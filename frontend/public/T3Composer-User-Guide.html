T³Composer 사용자 가이드 T³Composer User Guide

AI No-code React + Spring 자연어 · 설계서 · 기존 화면을 입력으로 받아 운영 가능한 화면(JSX + Java + SP + 메뉴 SQL)을 한 번에 생성·수정하는 AI 도구입니다. 본 가이드는 설치부터 전체 메뉴 사용까지 한눈에 안내합니다.
개발 경험이 없다면 초심자 가이드 를 먼저 보세요 — 용어 풀이와 5분 완주 실습으로 시작합니다. 두 문서 모두 사이드바 맨 아래에서 언제든 열 수 있습니다. An AI tool that generates and modifies production-ready screens (JSX + Java + SP + menu SQL) from natural language, design documents, or existing screens. This guide covers installation through usage of every menu at a glance.
New to development? Start with the Beginner Guide — plain-language glossary and a 5-minute walkthrough. Both documents are always available at the bottom of the sidebar.

💡 첫 기동 시간💡 First-time startup

최초 docker compose up 은 backend 의 Maven 의존성 다운로드 (수백 MB) 때문에 5~10분 걸릴 수 있습니다. 이후 기동은 30초 내. backend 가 healthy 상태가 되면 frontend 도 자동 작동합니다. The first docker compose up may take 5–10 minutes due to backend Maven dependency download (several hundred MB). Subsequent starts take under 30 seconds. Once backend is healthy, frontend works automatically.

⚠️ 포트 충돌⚠️ Port conflicts

5173 · 8090 · 15432 · 11433 중 이미 사용 중인 포트가 있으면 기동 실패. docker-compose.yml 의 해당 서비스 ports: 매핑을 변경하거나 기존 프로세스를 종료하세요. lsof -i :5173 또는 netstat -ano | findstr 5173 (Windows) 로 확인 가능. Startup fails if any of 5173 · 8090 · 15432 · 11433 are in use. Change the ports: mapping in docker-compose.yml or stop the conflicting process. Check with lsof -i :5173 or netstat -ano | findstr 5173 (Windows).

⚠️ .env 우선순위⚠️ .env precedence

.env 의 TARGET_*_DB_* 값이 채워져 있으면 매 backend 기동 시 그 값이 DB 의 UI 입력값을 덮어씁니다. UI 에서 일회성으로 바꿔도 다음 재기동 시 .env 값으로 되돌아갑니다 — 두 곳을 혼용하지 말 것. When TARGET_*_DB_* in .env is set, the backend overwrites the DB's UI-entered values at every startup. Even if you change them via UI for a one-off, they revert to the .env values on next restart — don't mix the two.

🔒 .env 보안🔒 .env security

.env 는 .gitignore 됩니다 (절대 commit 금지). API 키와 DB 비밀번호가 평문으로 들어가니 파일 권한 (chmod 600) 과 호스트 접근 통제 필요. .env is .gitignore'd (never commit). API keys and DB passwords are stored in plaintext — protect with file permissions (chmod 600) and host-level access control.

⚠️ CLI 모드 — 구독 한도 초과 시⚠️ CLI mode — when the subscription limit is hit

구독 사용량 한도를 넘으면 API 로 자동 전환되지 않고 즉시 실패합니다. 호스트에서 재로그인하거나 5시간 사용량 창이 끝날 때까지 기다려야 합니다. 옵션: LLM_CLI_TIMEOUT_MIN (기본 40) · LLM_CLI_MAX_CONCURRENT (기본 4). If the subscription usage limit is exceeded it fails immediately rather than falling back to the API. Log in again on the host or wait for the 5-hour usage window to reset.
