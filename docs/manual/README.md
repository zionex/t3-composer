# T3Composer — 사용자 매뉴얼

## 열람 방법

- 단일 HTML 파일을 더블클릭하면 브라우저에서 바로 열립니다 (외부 의존성 0 — 사내망/오프라인 환경 OK).
- 또는 git repo 안에서 IDE 미리보기로 열람 가능.

| 파일 | 내용 |
|---|---|
| [T3Composer-User-Guide.html](T3Composer-User-Guide.html) | **사용자 가이드** — 설치 → 7개 메뉴 사용법 → 부록 |

## 가이드 구성

- **§0 설치** — Docker 4-step (clone → .env → up → localhost:5173) · Insight LLM 옵션 · Target System 연결
- **§1 시작하기** — 사이드바 7개 메뉴 한눈 보기
- **§2 Composer (메인)** — 모드 선택 → 5개 모드 (자연어 / 단계별 + AI 추천 / 기존 화면 복사 / 자연어 수정 / 단계별 수정)
- **§3 History** — 작업 이력 / 이어하기
- **§4 SCM UI Mockup** — 운영 화면 mockup 갤러리 (54개)
- **§5 UI Pattern** — T3MES 패턴 카탈로그 (730 TabPage)
- **§6 Gallery** — Grid / Chart / KPI 사전 (위젯 후보)
- **§7 Ontology** — Q&A · Entity · View · Process
- **§8 Dashboard** — 위젯 빌더
- **§9 부록** — Target 전환 · API 키 등록 · 첨부 파일 · 단축키 / 팁 / FAQ
