② 다중 시나리오 병렬 구동 (Parallel Run)

안전재고 설정값이나 CAPA 한도를 다르게 한 여러 시나리오를 동시에 병렬로 구동하여 결과를 비교하기 위해 사용합니다.

③ 엔진 파라미터 튜닝 (Parameter Tuning)

엔진의 제약조건 가중치(납기 vs 원가)나 페널티 값을 미세 조정하여 최적의 플랜을 도출합니다.

④ 배치 스케줄 등록 (Job Scheduling)

매일 자정, ERP 데이터 수집 후 자동으로 엔진이 돌도록 Crontab 스타일의 스케줄을 등록합니다.

⑤ 마스터 데이터 사전 검증 (MDM Check)

엔진 구동 전, BOM 사이클 오류나 리드타임 누락 등 치명적인 마스터 데이터 오류를 사전 검출합니다.

⑥ 실행 승인 및 결재 (Approval)

운영 환경에 영향을 미치는 대규모 엔진 확정 전, 책임자의 시스템 결재를 득하는 화면입니다.

⑦ 전체 노드 상태 (Global Node Status)

분산 서버 환경에서 각 엔진 노드(서버)의 상태(Idle, Running, Error)를 카드 형태로 모니터링합니다.

⑧ 파이프라인 진척도 (Pipeline Progress)

데이터 로드 -> Heuristic -> LP -> 후처리 등 파이프라인 단계별 진행률을 바(Bar) 형태로 보여줍니다.

⑨ 실시간 엔진 로그 (Live Terminal Log)

엔진 내부에서 발생하는 상세 처리 로그와 계산 로그를 CLI 터미널처럼 실시간 스트리밍합니다.

CPU Usage (%)
Memory Usage (GB)

⑪ I/O 인터페이스 상태 (Data Ingestion)

ERP 등 외부 레거시 시스템으로부터 수집되는 I/F 데이터의 수신 현황 및 트래픽을 관제합니다.
인터페이스 (I/F ID)소스 시스템수신 건수마지막 수신 시간상태

⑫ 작업 대기열 큐 관리 (Job Queue)

현재 엔진에 쌓여있는 큐(Queue)를 보고 우선순위를 드래그로 조정하거나 대기 중인 잡을 취소합니다.
엔진 대기열 (Drag to Reorder)

⑬ 통합 오류/예외 로그 (Global Error Grid)

전체 시스템에서 발생한 Error, Warning 로그를 한눈에 볼 수 있는 통합 그리드입니다.
발생 일시수준 (Level)에러 코드모듈메시지 내용

⑭ 알람 임계치 설정 (Alert Threshold)

에러 발생 횟수나 지연 시간에 대한 임계치를 설정하여 관리자에게 이메일/문자로 발송하는 룰을 세팅합니다.
알람 룰 명칭트리거 조건 (Threshold)수신자 (Email)활성화

⑮ 장애 노드 원격 제어 (Node Recovery)

장애가 발생하여 Dead 상태가 된 엔진 노드를 강제로 Kill 하고 재시작(Restart) 시키는 강력한 제어 패널입니다.

⑯ 데이터 결측치 보정 (Data Imputation)

수요나 재고 데이터에 Null 등 결측치가 있을 때 엔진이 뻗지 않도록 룰에 따라 자동 보정(0 처리, 평균값 등)합니다.
대상 테이블컬럼명결측 건수보정 룰 (Action)처리 결과

⑰ 오류 담당자 할당 (Ticket Assign)

해결되지 않은 예외 건을 IT나 현업 담당자에게 티켓 형태로 강제 할당하여 처리를 유도합니다.
티켓 ID오류 요약담당 부서/자처리 기한상태

⑱ 장애 분석 리포트 (Root Cause Analysis)

엔진 실패 시, AI가 Stack Trace를 분석하여 실패의 근본 원인(Root Cause)과 조치 가이드를 제공합니다.
최근 치명적 실패 원인 분석 (RCA-2411-001)
[Root Cause] Memory Limit Exceeded during LP Matrix generation.
[Detail] The variable size reached 15,000,000 exceeding the 32GB RAM limit on Node-03.
[Recommendation] 1. Increase memory limit to 64GB or 2. Reduce scheduling horizon from 365 days to 180 days.

⑲ 수요/공급 밸런스 결과 (Supply-Demand)

엔진이 도출한 기간별 수요 대비 생산/공급량의 밸런스를 확인합니다. (붉은색은 공급 부족 구간)
기간 (Week)총 수요 (A)총 공급 (B)Balance (B-A)상태

⑳ 핵심 KPI 전/후 비교 (KPI Before/After)

엔진 구동 이전(계획 전)과 엔진이 도출한 최적화 결과 간의 핵심 KPI 향상도를 비교합니다.

㉑ 안전재고 위반 경고 (Safety Stock Alert)

엔진 계획상 미래의 특정 주차에 안전재고(SS) 밑으로 재고가 뚫리는 품목 리스트를 모아 보여줍니다.
위반 품목발생 예상 주차안전재고 기준예상 재고위험도

㉒ 납기 지연 예상 오더 (Late Orders)

설비 캐파나 자재 제약으로 인해 고객이 요청한 납기를 도저히 맞출 수 없는 수주(SO) 목록입니다.
